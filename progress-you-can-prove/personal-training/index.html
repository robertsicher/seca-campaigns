The Progress Consultation

A six-step model gyms could adapt to onboarding, coaching or premium assessment.

01 / Measure

Establish a baseline

Use body composition to create a more useful starting point.

02 / Understand

Interpret the result

Help the member understand what the measurement does and does not mean.

03 / Set a goal

Agree an objective

Connect the result to a meaningful training target.

04 / Train

Build the programme

Translate the goal into an appropriate coaching plan.

05 / Remeasure

Review after an agreed period

Create a structured reason to return and assess progress.

06 / Progress again

Inform the next block

Use the review to shape the next programme or consultation.

Potential use cases: new-member onboarding, premium assessments, PT introductions, transformation programmes and coaching packages.

Campaign Strategy

Interview mode

Objective

Create demand for TRU Alpha within UK health and fitness by connecting a measurable member problem to a commercial operator outcome.

Audience

Premium operators first, specialist and performance gyms, then larger national groups where a pilot can build evidence for rollout.

Campaign model

Problem → content → calculator → HubSpot identification → nurture → demo → pilot → measurable commercial proof → rollout.

Measurement

Traffic → engaged target accounts → calculator completions → MQL → demonstrations → pilots → opportunities → pipeline → closed revenue → subsequent service/customer lifetime value.

The purpose is not to claim a commercial uplift before evidence exists. The campaign creates useful hypotheses, captures operator economics, then uses pilot data to validate what actually changes.
