Campaign Strategy

Interview mode

Objective

Create demand for TRU Alpha within UK health and fitness by connecting a measurable member problem to a commercial operator outcome.

Audience

Premium operators first, specialist and performance gyms, then larger national groups where a pilot can build evidence for rollout.

Campaign model

Problem → content → calculator → HubSpot identification → nurture → demo → pilot → measurable commercial proof → rollout.

Measurement

Traffic → engaged target accounts → calculator completions → MQL → demonstrations → pilots → opportunities → pipeline → closed revenue → subsequent service/customer lifetime value.

The purpose is not to claim a commercial uplift before evidence exists. The campaign creates useful hypotheses, captures operator economics, then uses pilot data to validate what actually changes.
